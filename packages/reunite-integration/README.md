# @redocly/reunite-integration test

The part of Redocly CLI that talks to [Reunite](https://redocly.com/docs/realm): the API client, the OAuth client behind the `login` and `logout` commands, and the functions behind the `push`, `push-status`, and `scorecard-classic` commands.

This package exists for [Redocly CLI](https://github.com/Redocly/redocly-cli) and [reunite-push-action](https://github.com/Redocly/reunite-push-action).
To work with Reunite from the command line, use Redocly CLI and its [command reference](https://redocly.com/docs/cli/commands).
